Design toolkit GitHub

Tweak the design on the page. Let your agent write the code.

A tiny toolbar for your localhost. Edit text, radius, spacing and layout where you see them, then copy one prompt for your coding agent.

Test

Features

  • Text

    Click any copy and type. Deleting counts too.

  • Radius

    Drag a corner with Move, or type it in the panel.

  • Spacing

    Drag padding, margin and gap, with Figma's keys.

  • Move

    Reorder, re-parent, or place it freely.

  • Comment

    Leave a note on any element or selected text.

  • Delete

    Select an element with Move and press delete.
