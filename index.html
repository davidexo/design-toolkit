Tweak the design on the page. Let your agent write the code.

A tiny toolbar for your localhost. Edit text, corner radius, spacing and layout right where you see them, then copy one prompt that tells Claude Code (or any coding agent) to make the same changes in your source.

It is running on this page. Press T R S or V and try the demo below.

How it works

Three steps, no build tools, no account.

  1. Tweak. Pick a tool from the toolbar at the bottom and change things on your running app. Values snap to a 2px grid.

  2. Copy prompt. Press ⌘↵. You get one prompt with every change, where it lives in the DOM and which React component renders it.

  3. Paste into your agent. It finds the source and makes the edit. Your dev server's hot reload shows the result.

Install

Paste into your coding agent.

Tools

While a tool is on, clicks never reach your page, so links and buttons stay put.

T TextClick any copy and type. Deleting text counts too.
R RadiusDrag the corner handle, step with ↑ ↓, or press ↵ to type a value.
S SpacingDrag padding, margin and gap bands with Figma's keys: ⌥ mirrors the opposite side, ⌥⇧ all sides.
V MoveDrag into any container to reorder or re-parent. Switch on Absolute to place it freely, with an optional annotated screenshot.
⌘↵Copy the prompt. The Tokens switch decides whether your agent maps values to your design tokens or uses them as is.
EscDeselect, then leave the tool.
